# Spike findings

One file per spike, named after its issue (for example `02-vinext-on-workers.md`). Each says what was tried, what worked, what did not, and the recommendation the rest of the repo should follow.

The docs site publishes these notes as its Research section (`apps/docs-site/scripts/research.mjs`), so write them for a public reader and link to other notes and repo files with relative paths.
