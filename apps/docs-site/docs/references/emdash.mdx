[`apps/emdash`](https://github.com/patronage/launch/tree/main/apps/emdash) is one Astro app on one Worker. It renders the site with the same sections as the WordPress and Payload sites and serves EmDash's admin and API. See [ADR 0022](https://github.com/patronage/launch/blob/main/docs/adr/0022-emdash-renders-the-site-in-astro.md).

## How it fits together

| Concern | How |
| --- | --- |
| Content | `getEmDashEntry` reads D1; `@launch/adapter-emdash` maps pages to the content model |
| Rendering | `PageSections` and the site chrome from `@launch/ui`, rendered on the server; nothing hydrates |
| Storage | D1 for content, R2 for media, served publicly at `/media/*` |
| Publishing | Edits show once published; a cron trigger publishes scheduled entries |
| Preview | EmDash's signed `_preview` link shows that one entry's draft, uncached |
| Sign-in | Cloudflare Access on `/_emdash/*`, through EmDash's `access()` auth; the site stays public |
| Redirects | EmDash's own: exact and pattern rules, 301s on slug changes, a 404 log |
| SEO | Each entry's SEO panel, `<EmDashHead>` meta and JSON-LD, `/sitemap.xml` and `/robots.txt` |
| Forms | `@emdash-cms/plugin-forms`, placed with a `form` section; submissions in the admin, posted to the public `/forms/submit` |
| Email | Cloudflare Email Sending through EmDash's `cloudflareEmail` plugin, on when `EMAIL_FROM` is set at deploy; the sender's domain must be onboarded for Email Sending |

## Editing

- **Hero**, on pages, in the same variants as WordPress and Payload.
- **Sections**: a blocks field with content, content and media, media, card grid, blockquote and call to action blocks, each with the shared Section options.
- **Rich text** is EmDash's Portable Text. The adapter renders paragraphs, headings, quotes, lists, marks, safe links and images.
- **Forms** are built under Plugins > Forms and placed on a page with a `form` section.
- **Menus and settings**: the site title, tagline and `primary` menu feed the header and footer.

The schema and demo pages are code (`apps/emdash/seed/build.ts`), applied when a database is new.

## Not yet covered

- Pull quotes, embeds and buttons inside rich text.
- Page caching with EmDash's cache hints.
