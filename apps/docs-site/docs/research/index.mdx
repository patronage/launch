Before anything is built for real, each open question gets a spike: a small, throwaway app that answers it. Each finding says what was tried, what worked, what did not, and what the rest of the repo should do.

These pages are published from [`docs/spikes`](https://github.com/patronage/launch/tree/main/docs/spikes) in the repo each time the site builds, so they always match the notes. They are named after the GitHub issue that asked the question. The settled outcomes are collected on [Decisions](/decisions).
