title: Launch
description: Reference sites from Patronage for running a CMS behind Cloudflare Access, with fast front-ends on Cloudflare Workers.
---

Launch is Patronage's open-source monorepo of reference sites. Each one renders the same invented demo site from a different CMS, and in every case the CMS admin and API sit behind Cloudflare Access while only the public site is open.

| Reference | CMS | Front-end |
| --- | --- | --- |
| Headless WordPress | WordPress with WPGraphQL | vinext on Workers |
| Payload | Payload, one app on the Local API | vinext on Workers |
| Traditional WordPress | WordPress with a Timber theme | The theme itself |

All three render the same invented demo site, Neighborhood Growers, from the same CMS-neutral content model: the same pages, heroes, page sections, forms and rich-text blocks. The news posts differ between the WordPress and Payload seeds. The vinext front-ends share one UI package, and the Timber theme shares its design tokens.

Around the reference sites, Launch also ships:

- an [MCP server](/references/mcp) per site, so a team can read the CMS from Claude, Codex or Cursor and make changes a person approves;
- [logging](/references/logging) of every Worker request and WordPress event to the site's own R2 bucket;
- a [WordPress deploy kit](/deploy/wordpress) for pushing either WordPress install to its host.
