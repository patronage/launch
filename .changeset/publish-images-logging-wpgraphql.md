First npm releases. `@patronage/images` (formerly the private `@launch/images`) serves CMS images through the Cloudflare Images binding. `@patronage/logging` publishes the Worker wide-event wrapper and the Cloudflare log-store helpers. `@patronage/wpgraphql` is the framework-neutral WPGraphQL transport taken out of the headless WordPress front-end: Access service token and preview identity, persisted query IDs, Smart Cache tags, typed read errors and `upstream.wordpress` timing.
