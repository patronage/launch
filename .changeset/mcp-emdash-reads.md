New package: the `emdash` connector for the MCP gateway. `emdash.get` reads EmDash's REST API as the signed-in editor, from an allowlist of content, revision, schema, media, menu, taxonomy and search routes, and `describe_site` lists the editor's collections, fields, taxonomies and role. It doesn't write yet.
